# Задание 4. Логирование

### Проанализируйте систему компании

INFO:

- создание заказа (идентификатор покупателя, номер заказа)
- изменение заказа (идентификатор покупателя, номер заказа)
- удаление заказа (идентификатор покупателя, номер заказа)

Так как в системе теряются заказы, возможно где-то в монолитах есть ошибки: по этому я бы добавил логи уровня ERROR.

ERROR:
- ошибки в работе сервисов(идентификатор реквеста, боди, заголовки, метод и трейс)

### Мотивация

Добавление логирования поможет отследить причины просроченных и потерянных заказов, ускорить процесс отладки багов, выявить проблемы в сервисах, повысить скорость доставки новых функций и улучшить общее качество сервиса.

### Предлагаемое решение

[Схема](./schemes/schema.drawio)

Для сбора и анализа логов в системе будет использоваться стек ELK для агрегирования, обработки, анализа и визуализации логов.  
Для этого необходимо развернуть стек ELK.

**Безопасность**

Для работы с чувствительными данными необходимо настроить Logstash для преобразования данных, которые могут содержать персональные данные пользователей. Доступ к логам будет предоставлен разработчикам и бизнесу.

**Хранение**

Логи с каждого монолита можно разнести по отдельным индексам в Elasticsearch для упрощения работы с ними. Логи будут храниться в течение месяца — этого срока достаточно для анализа. Также необходимо рассчитать и предусмотреть оптимальное место для хранения логов исходя из времени хранения.

### Проработайте необходимые мероприятия для превращения системы сбора логов в систему анализа логов

Для анализа логов можно использовать BI-системы и интегрировать их в сервис. В описании задачи приведён пример аномалии — можно настроить систему таким образом, чтобы она предусматривала подобные кейсы и отправляла соответствующие алерты. Также на основе логов можно получать бизнес-аналитику.
Минусом может быть, что для этого потребуется инженер, который обладает экспертизой в работе с BI-инструментами, на данный момент в команде такого человека нет. Если бизнес решит, что аналитика нужно, значит инженера нужно будет нанимать.
